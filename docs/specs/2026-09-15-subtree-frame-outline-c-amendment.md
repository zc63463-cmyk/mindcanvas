# 子树框编辑 · 产品修正 FO-C（紧凑大纲 + 框体积碰撞）

- **日期**：2026-09-15
- **状态**：已确认，待外派 FO-C1 → FO-C2
- **上游**：`docs/specs/2026-09-15-subtree-frame-outline-design.md`（一期已交付）；用户实测偏差反馈

## 0. 问题（相对一期交付）

1. 框内仍像「节点卡排版」——行盒复用画布 `measure(node)`，不紧凑。
2. 文本单行 `ellipsis` 裁切——不是大纲式自动换行。
3. 框壳无布局体积——不参与邻节点碰撞/分离（B1 已知债）。

## 1. 已确认口径

| 项 | 裁定 |
|----|------|
| 框内 text | 紧凑大纲行；固定**内容列宽**自动换行；高度随行数涨；编辑态同宽换行 |
| 框内 image/entity | 仍占位，但扁、紧凑；不内联改 url/ref |
| 框宽策略 | **固定内容列宽**（常量，如 `FRAME_OUTLINE_CONTENT_W`），不随最长未折行字串无限撑开 |
| 框体积 | 外壳 AABB（大纲区含换行增高 + padding；**C2 壳可不含挂出**；**C2.1** 占位壳含挂出外包络推邻居，见 `docs/dispatch/2026-09-16-fo-c2.1-hang-envelope-shell-prompt.md`） |
| 碰撞 | 框壳 AABB 参与与邻节点/邻岛的分离；内容变高 → 外层重排 |
| 数据 | 仍不新 `type`；仍 `note.frame` + children 不搬家 |

## 2. 分阶段

| 阶段 | 目标 |
|------|------|
| **FO-C1** | 紧凑行度量 + 换行渲染 + 换行编辑态（体感立刻对） |
| **FO-C2** | 框壳占位写入布局 + 碰撞/分离（体积真正「顶得住」） |

派发文件见 `docs/dispatch/2026-09-15-fo-c*-prompt.md` 与 overview 更新。
