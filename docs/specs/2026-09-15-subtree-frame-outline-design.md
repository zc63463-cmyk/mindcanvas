# 子树框编辑（局部大纲 · 按深度挂载）设计稿

- **日期**：2026-09-15
- **状态**：**已认可 · 实现计划已出**（见 `docs/superpowers/plans/2026-09-15-subtree-frame-outline.md`）
- **定位**：画布上「空间导图」与「局部可写大纲」的持久互转；上游 = 现有 `EditableNode` 树 + 幕布注释 + 只读 `OutlinePanel`（Ctrl+D）
- **一句话**：选中节点**成框**后，按可配置深度把浅层后代收进**框内可写大纲**（节点内容 + 幕布快速注释），更深后代仍以**空间节点**挂在对应大纲行的挂点上；数据仍是同一棵 `children` 树，仅持久 `note.frame` 元数据；**不新增 `type`**。

## 0. 设计原则

1. **单一事实源**：框不拷贝子树；大纲编辑的就是同一批 `EditableNode`（全保真往返）。
2. **扩展缝优先于新类型**：成框 = `note` 透传键，不进 `EditableNode.type` 联合（对齐翻卡 `note.md` / sections 纪律）。
3. **深度切分，而非整树吞进大纲**：支持自定义 `depth`；大纲层与空间挂载层共存。
4. **持久框是一等公民**：成框状态随文档保存/重开；可拆框、可改深度。
5. **嵌套有条件禁止**：禁止「大纲层内再成框」；允许「空间挂载层上的后代再成框」。

## 3. 协议

### 3.1 字段形状

挂在**成框节点**自身的 `note` 上：

```yaml
note:
  frame:
    version: 1
    depth: 2   # 整数 ≥ 1；从框根起算，前 depth 层进大纲
```

| 操作 | 行为 |
|------|------|
| 成框 | 写入 `note.frame`（若无 `note` 则创建） |
| 拆框 | 删除 `note.frame`；其它 note 字段不动 |
| 改深度 | 只改 `depth`；不改 `children` 拓扑 |

- **缺省 / 无字段** = 非框。
- mm-md 协议需登记 `frame` 键名与版本；旧客户端忽略未知键 → 子树仍完整，仅无框外壳。
- TypeScript：在 `Note` 上增加可选 `frame?: { version: 1; depth: number }`（或等价类型），与透传兼容。

### 3.2 深度语义（D1）

相对框根深度 `d`（框根 `d = 0`）：

| `d` | 呈现 |
|-----|------|
| `0` | 框头 / 框标题（可编该节点内容 + 其幕布注释） |
| `1 … depth` | 框内大纲行（内容 + 幕布注释） |
| `> depth` | 空间导图节点；锚在祖先链上「`d = depth`」那一行的挂点 |

### 3.3 嵌套纪律（修正 N3）

以最近成框祖先 `F`（其 `depth = D`）为准，候选节点 `C` 相对 `F` 的深度为 `d`：

| 情况 | 条件 | 成框 |
|------|------|------|
| 大纲层内 | `1 ≤ d ≤ D` | **拒绝**（一期） |
| 空间挂载层 | `d > D` | **允许** |
| 无成框祖先 | — | **允许** |

说明：祖父框 `D` 较浅时，挂在大纲挂点上的深层树节点可以再成框——这不是「框内大纲套框」，而是挂载层上的独立框。

## 4. 交互

### 4.1 成框

- 入口：选中节点 → 右键「成框编辑…」和/或命令面板（快捷键一期可暂缓）。
- 校验：按 §3.3；失败 toast，不写盘。
- 深度 UI：轻量步进器；默认 `depth = 2`；范围 `1 … min(8, 子树最大深度)`；超出实际高度时按实际切分并提示。
- 确认后写 `note.frame`，布局切岛。

### 4.2 框上操作

- **改深度**：框头/框角控件；只重排，不改拓扑。
- **拆框**：删 `note.frame`；恢复普通森林布局。
- **选中**：单击大纲行 = 选中对应节点（共用现有选中模型）。
- **编辑**：双击行内文本就地编辑（对齐现有节点编辑）；幕布注释用折叠副行或既有注释入口（一期范围：`desc` / `note` / `note_text`）。

### 4.3 框内可编范围

- **做**：`text` 主内容；幕布快速注释；Tab / Shift+Tab 升降级；Enter 建兄弟 → 映射 `treeOps`。
- **不做（一期）**：大纲内改 image `url` / entity `ref`（只读占位 + 点选）；框内编自由边；框内翻 `note.md`；框内 ▸ 折叠落盘。

### 4.4 与全局 OutlinePanel

- 全局面板仍只读导航。
- 框 = 画布局部可写大纲；选中态可与面板双向同步（点行 ↔ 画布选中）。

### 4.5 撤销

成框 / 拆框 / 改深度 / 大纲改树 → 同一撤销栈。

## 5. 布局与挂点

### 5.1 布局岛

成框节点 = 一颗布局岛：

1. **大纲区**：排 `d ∈ [0, depth]`；外壳尺寸 = 大纲包围盒 + padding（内容撑高，触发岛重排）。
2. **挂点**：仅 `d = depth` 的行在子侧有逻辑锚点（非协议节点）。
3. **空间层**：`d > depth` 的子树从对应挂点用**现有子树布局**继续排。

示意（`depth = 2`）：

```
┌─ Frame(root) ─────────────────────┐
│ root                              │
│   ├─ A          ●── A 的深层子树…  │
│   └─ B          ●── B 的深层子树…  │
└───────────────────────────────────┘
```

### 5.2 交互约束（一期）

- 深层空间节点：照常选中 / 拖拽排序 / 双击编辑（在挂点父之下）。
- **禁止**跨 `depth` 边界拖拽改层级（进/出大纲层）；跨界改层级用大纲 Tab/Enter 或先改 `depth`。
- 框根被全局折叠 → 整岛（大纲 + 挂出子树）隐藏，与现有折叠一致。
- 一期**不做**框内大纲 ▸ 折叠（避免与文档 collapsed 分叉）。

### 5.3 改 depth

- `depth`↑：原挂点行并入大纲，空间子树挂到新的 depth 行。
- `depth`↓：原大纲深层行变挂点行，其子树改挂新点。
- 只重排，不改 `children` 拓扑。

### 5.4 性能

岛为普通布局子问题；cull 用岛 + 挂出子树外包络，复用 `CULL_MARGIN`；一期不为框单独做虚拟化。

## 6. 与现有能力的关系

| 能力 | 关系 |
|------|------|
| `note.sections` | 文档级空间分区；成框不写 sections，标 Section 不成框 |
| Ctrl+D 大纲 | 只读导航；框内才可写 |
| 幕布注释 | 框内可编，语义不变 |
| `note.md` 翻卡 | 框内不翻面；可经既有面板对选中节点翻卡 |
| 自由边 | 成框不改边数据；一期不在框 UI 内画/编边 |

## 8. 失败与降级

| 情况 | 行为 |
|------|------|
| `depth` 非法（≤0、非有限、非整数） | **写时校验拒绝**；读时钳到合法整数范围（实现计划钉测试） |
| `depth` > 子树实际高度 | 布局按实际高度切分；**保留**盘上 `depth`；UI 可提示可裁切 |
| 旧客户端无框逻辑 | 忽略 `frame`，整树按普通节点渲染 |

## 9. 验收直觉

1. 成框 → 保存 → 重开：框仍在，`depth` 不变。
2. 大纲改标题 / 幕布注释 → 拆框后字段仍在对应节点。
3. 深层空间节点 id 不变，可被搜索 / 自由边引用。
4. 祖先框大纲层内节点成框 → 拒绝；挂载层节点成框 → 成功。
5. 拆框后无 `note.frame`，布局回到普通森林，数据无第二份拷贝残留。
