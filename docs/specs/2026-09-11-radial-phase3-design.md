## 1. ① 幽灵预览（画布版）

### 1.1 目标
环内高亮「新建子节点」→ 在生长方向显示**虚线幽灵节点**（即将创建的预告）；高亮「删除节点」→ 节点 + 整棵子树**红色虚线描边**（删除范围预告）。预览页已有同形实现，本次搬到主画布。

### 1.2 交互
- 幽灵位置 = 生长方向侧的兄弟位，与 `addChild` 命令**同源推断**（`preDirsRef` → `inferChildDir`），保证「看到的落点 = 提交后的落点」
- 尺寸：按「新节点」文本近似宽高（与测宽公式一致）× 当前缩放 `k`；内容「新节点」
- 删除描边：子树所有节点盒红色虚线（只描边、不遮内容）
- 全部 `pointer-events: none`，z-index 59（环 60 之下）；贴视口边缘时幽灵向内收

### 1.3 技术方案
- `MapViewApi` 新增（只读，与 `nodeCorner` 同构逆变换）：
  - `nodeBox(id): { x; y; w; h } | null`（客户端坐标；未命中 → null）
  - `subtreeBoxes(id): Array<{ id: string; x; y; w; h }>`（含自身；未命中 → 空数组）
- 纯函数（可单测）：`ghostBoxOf(nodeBox, dir, k, gap)` —— 四向偏移（right: `x+w+gap`；down: `y+h+gap`；left/up 对称）+ 视口内收
- 组装在 `MindmapStage`（**单一动作源纪律**：方向推断与 addChild 同一处）→ 以 props 传给 `RadialStageOverlay`：`ghost?: { box; label }`、`dangerBoxes?: Box[]`
- 渲染：`RadialStageOverlay` 内 fixed 定位 div；样式入 `RADIAL_SURFACE_CSS`（新增 `.ghost-node` / `.danger-box`）

### 1.4 测试
- 纯函数：`ghostBoxOf` 四向 / 贴边内收 / k 缩放
- 组合：视觉部分以纯函数测试 + 页面手工验收为准（hook 层不断言视觉）
- 回归：无高亮时**零渲染**（不产生任何幽灵/描边 DOM）

### 1.5 风险与取舍
- 新节点宽度不可知 → 近似估算（YAGNI：不做真实 measure 预排）
- 贴边时幽灵可能出屏 → **决策点 A1**

## 2. ② 二级环

### 2.1 目标
「更多操作…」不再跳右键菜单，改为**环内二级**（外圈浮现），把右键菜单里「高频 · 一次性 · 无参数 · 无（或生僻）快捷键」的动作收进环。
右键菜单**不删能力**为原则，但按「环内可达」重新分工（§2.2.3）：首屏只留环外独有项，被环覆盖项降入长尾区或（有等价入口时）物理移除。

### 2.2 交互（定案 + 实测修正）
- **一级环保持 4 项**（新建子节点 / 编辑文本 / 删除节点 / 更多操作）——2026-09-12 用户定案：不加席
- 一级高亮「更多」并确认（悬停停顿 `dwell` ≈450ms，或点击 / Enter）→ 外圈浮现**二级环**（同心、缺口语义继承）
- **二级席位：7 席**（数据序 = 角度序，可用弧均分；296° ÷ 7 ≈ **42.3°/席**，中半径 ≈70px → 命中弧长 ≈52px，仍在舒适线内）：

| # | 席位 | 条件 | 收敛依据 |
|---|---|---|---|
| 1 | **新建同级节点** | 非根 | v1.8.2 追加（用户拍板）：环内原本缺「同级」这条生长路径（Enter 在环内是提交键）——第 1 席 = 下钻后指针最先够到的位置，留给最高频的生长动作；与菜单「常用 › 新建同级节点」同命令 |
| 2 | 编辑描述（盒内） | 恒 | 高频内容入口；一级未覆盖（另有 Shift+Enter 双代偿） |
| 3 | 编辑笔记（盒下） | 恒 | 内容入口；**菜单之外无第二入口** → 环成为主入口 |
| 4 | 升为中心 ⌄（方向型 → 翻页） | 非根且非中心 | 用户点名纳入；四向动作由**外圈翻页**承载（不加深层级） |
| 5 | 升级 / 取消出线枢纽 | 非根 | 布局核心开关（动态文案，无快捷键） |
| 6 | **剪贴板席（动态）**：是中心且有 cid → 复制中心编号；否则 → 复制节点文本 | 恒（无 cid 时退化） | 剪贴板是通用动作：动态化后**席位恒无空缺**（原「不可用即灰显」在默认态几乎不可见 alpha 0.07 + 不可悬停 + 轮转跳过，实测被读成「席位空缺」）；「复制节点文本」与菜单项**共用命令**（`edit/sharedCommands.ts`） |
| 7 | 打开完整菜单（右键） | 恒 | **兜底末席**：保底可达一切（渐进披露出口） |

- 条件不满足 → 该席 `disabled` **灰显**（与一级 disabled 规范一致），**不改席位顺序与角度**；
  灰显渲染 = 暗（alpha 0.13）+ **虚线**（「锁着的席」，不是洞——0.07 实心实测被读成空缺）
- **翻页（方向型动作的承载）**：选中「升为中心」→ **同一外圈换页**为方向席位 `右 / 左 / 下 / 上 / 返回`（末席恒为「返回」）；
  页内 `←→` 轮转、Enter/点击提交、**点内圈 = 回上一页/上一级**、Esc = 收起。**仍是二级深度**（不是三级菜单）
- 提交：二级内 Enter / 点击 / 松 Alt 提交；**Esc / Backspace = 收起**（整环）
  - **v1.8.2 实测修正**：Windows 把 `Alt+Esc` 当系统快捷键（切窗口）→ 环内 Esc **永远收不到**，
    「Esc 先降级」不可达；**降级返回一级 = 点内圈（主环带）**（B3 推荐采纳）或松开重进
- 明确不进环：生长方向（`Alt+方向` 预方向通道已覆盖）、出线长度（数值型 + 拖梁通道）、缩进/反缩进（Shift+Tab）、
  折叠/展开（Space）、模式限定（连线到… 仅关系模式）、状态类元数据（标记/取消 Section、显示隐藏父级连接、detached 接回）——留在菜单

### 2.2.3 菜单分工与瘦身（本次规划）

| 处置 | 项 | 理由 |
|---|---|---|
| **阶段 1 物理移除（4 项）✅ 已执行（T6）** | 编辑描述 / 编辑笔记 / 升级·取消出线枢纽 / 复制中心编号 | 均有环内席位（等价入口）；描述另有 Shift+Enter 双代偿。跨模块不变量测试钉死「被移除项必须仍存在于环席位」 |
| **方向/参数型收成「一行 + 子页」✅ 已执行（T6）** | 升为中心（4 向）· 生长方向（4 向 + 继承）· 出线长度（预设 + 缺省 + 自定义） | `ContextMenuItem.page` = 菜单内**翻页**（与环「同一外圈换页」同语义）；行内显示**当前值**，行尾 hint 指出更快通道（Alt+方向 / 拖梁 / 环：更多），行尾 `›` = 有子页 |
| **v1.8.2 新增（1 项）** | 复制节点文本（内容区） | 与环剪贴板席**共用命令**（`sharedCommands.copyNodeTextToClipboard`）——环外也可用，避免「只能在环里复制」的反直觉 |
| **保留原位（不动）** | 常用（新建/同级/编辑/删除，与一级环对齐）· 内容-实体项 · 结构（缩进/反缩进/折叠/连线到…）· 岛与区域状态项（降格/父级连接/接回/Section 三态）· 清除左右残留（条件项） | 环外独有 / 条件型 / 危险型 |

- 净效果（T6 实测）：普通节点菜单 **28 → 12 行**（−4 移除 −3×3 折叠 +1 复制文本）；首屏「常用 + 内容」= 5 行；
  实体节点 +3（改引用 / 在关系图中显示 / 转为纯文本）、关系模式 +1（连线到…）
- 菜单**进入子页后首屏只有该组选项 + 「‹ 返回」**（与环的二级页对称）；`Esc` 一键关闭、`←`/`Backspace` / 「‹ 返回」= 回上一页
- v1.8.2 顺带修（真浏览器实测）：**菜单视口钳制**——节点贴底/右边右键时菜单顶出屏幕、下面的行点不到；
  现在按实测尺寸收进视口（边距 8px）+ `max-height: 100vh-16px` 溢出兜底

### 2.3 技术方案（已实现 + 待做）
- **已实现（v1.8.2 沙盒）**：
  - `edit/radialActions.ts`：`level / parentSlot / subIndex` + `RadialSubItem` 池（4/5/6 裁剪）+ `subRingOf / hitSubSeat / hitInnerRing / subSeatCenterDeg`
    + reduce 分支（一级「更多」提交 = **下钻**；二级 ←→ 轮转 / Enter·点击·松 Alt 提交 / 点内圈 **降级** / Esc 收起）；
    `ctx.sub` 缺省时**逐字节走原路径**（画布零影响，测试钉死）
  - `chrome/radialSurface.tsx`：`SubRing`（段式弧规范，外圈 z 58）+ `.ring-dim`
  - 预览页 `/radial.html` 沙盒：开关 / 席位 4–6 / 展开延时 200–800ms（§1 的手感调参）
- **已实现（T1–T5）**：
  1. ✅ `RadialSubItem.disabled`（灰显不抽席）+ 外圈**页**（`subPage` + 页内 items，复用同一几何）
  2. ✅ **派生入口** `submenuItemsFor(controller, id, bags)`：静态顺序模板（**主 7 席**）+ 条件过滤（转 `disabled`）
     + 动态文案（枢纽/中心/剪贴板席）+ 页定义（升为中心 → 方向页）；与 `contextMenuItemsFor` **同动作闭包**
  3. ✅ 画布接线（T5）：`useRadialStage.getSubModel` → `ctx.sub`；`sub:*` → 模型动作闭包（末席 `openMenu` 兜底）；
     「更多」停顿 450ms 下钻；`RadialStageOverlay` 渲染外圈/主环降透明/二级浮标；

  4. ✅ 菜单瘦身（T6）：移除 4 项 + 方向/参数型收成「一行 + 子页」（`ContextMenuItem.page`）+ 行内当前值

  6. ✅ 帮助与文档（T7）：`ShortcutHelpPanel` 二级 7 席清单（标签从派生模型取）+ `keys.ts` 两行
  5. ✅ 预览页接**派生**席位（可切「模拟根/中心/枢纽」看条件灰显与翻页）
- 测试：纯逻辑（页切换 / disabled 席不可提交 / 席位与菜单条目一致性）+ 画布接线（`sub:*` → controller 动作闭包）
  + 真实浏览器（主画布：松键提交真建同级节点）

### 2.4 风险与取舍
- 可发现性：阶段 1 移除的 4 项只能经环到达 → 缓解：① 一级「更多」扇区图标即「⋯」语义；② 菜单保留「升为中心」等引导项 + hint；
  ③ 帮助面板（`?`）补二级席位清单

## 3. ③ 动作频率学习

### 3.1 目标
让常用动作更快可达——**但绝不重排一级环扇区**（破坏 marking 肌肉记忆是反模式，Phase 1 设计已定论）。

### 3.2 方案（A/B 叠加；C 明确不做）
- **A（推荐）**：开环时**默认高亮 = 上次提交的动作**（零位移、零风险，连续同操作提速）
- **B**：二级环 / 「更多」子项按**个人频次排序**（依赖 ② 的接口）
- **C（拒绝）**：一级扇区按频率重排

### 3.3 技术方案
- 存储：`localStorage['mindcanvas.radial.freq.v1'] = { [itemId]: count, __last: itemId }`；损坏/不可用 → 空表（try/catch，参照 `fileManagerShared.ts` 星标先例）；上限 64 键防脏数据
- 写入：commit 成功时 `bump(itemId)`
- 纯函数（packages/react）：`bumpFreq(map, id)` / `orderByFreq(items, map)` / `initialHighlight(last)`
- 作用域：全局（非按文档）——**决策点 C1**；「重置学习数据」入口放帮助面板——**决策点 C2**
- 测试：纯函数 + hook 层（提交后写入 localStorage / 开环预高亮）

### 3.4 风险
- 预高亮 A 的误触：默认高亮 ≠ 默认提交（仍需松 Alt）——**决策点 C3**（推荐：不加保护窗，保持简单）

## 4. ④ 触屏长按

### 4.1 目标
平板/触屏本可用环形菜单（复用同一状态机与渲染）。

### 4.2 交互
- 长按节点 **300ms**（期间位移 > 8px 取消）→ 环浮现
- 锚点：节点右上角（同桌面）；手指遮挡时整环上移 24px——**决策点 D1**
- 拖动手指 → 悬停高亮（pointermove 驱动）；松手 → 提交高亮项 / 无高亮关闭
- 长按触发前移动 = 原节点拖拽逻辑；触发后移动 = 环内漫游（不再拖节点）
- 可选：触发时 `navigator.vibrate(10)` 反馈

### 4.3 技术方案
- **状态机零改动**：`useRadialStage` 新增触屏会话 API `beginPress / pressMove / endPress`，内部发 `alt-down / hover / alt-up` 等价事件
- 长按计时 + 位移判定在 hook 内（假定时器可测）；仅 `pointerType === 'touch' | 'pen'` 生效
- 手势接线：`packages/react/src/render/useMapGestures.ts` 增 `onNodeLongPressStart / Move / End` 回调（与 nodeDrag 判定链并列，命中节点才启动）；`MindmapStage` 转接到 radial hook
- 触屏会话内：吞 `contextmenu`、画布容器 `touch-action: none`、阻止文本选中
- 测试：hook 层（300ms 触发 / 移动取消 / 松手提交 / 短按不触发 / 鼠标不触发）+ useMapGestures 层（长按与拖拽互斥）

### 4.4 风险
- iOS 长按系统菜单/文本选中的对抗（preventDefault + touch-action）
- 验收方式——**决策点 D2**
