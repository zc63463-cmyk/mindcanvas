怎么读这张表
· 平均 |曲率| 越低越平；最大弧高/弦长 是最夸张那条线鼓出去多少（超过约 60% 就会显得绕远）。
· 与树线交叉 是视觉噪声指标 —— 关系线压过父子连线越多，图越乱。
· 穿障边数 必须为 0，非 0 即为缺陷。
· 弯曲绕行边数 的比例反映"有多少条边真的需要绕"；无障碍的短边本该直连。

调节方向：觉得弧太大 → 调小 corridor / 调大 bend（往 C 走）； 觉得还是贴中心 → 调大 corridor / 调小 bend（往 D 走）。
