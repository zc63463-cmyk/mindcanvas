03设计令牌候选方向（翻卡）

三个候选方向已按 mindcanvas 定位（纯文本事实源 + 实体可升格 + 库优先）预筛。点击卡片翻转查看适配评估——这是你钦定 K3 方向的素材，最终决定权在你。

方向 A · 推荐

墨纸极简

暖纸底 + 墨色文字 + 单强调色
无框文本节点 · 细灰贝塞尔线

适配评估

墨纸极简

与纯文本内核气质最合：节点即文字，升格实体才显色。留白承载思考。实现成本最低。硬伤：无框节点对选中/拖拽的交互反馈需额外设计。

方向 B

手绘松弛

波浪线 + 不规则节点
蜡笔色点缀 · 弹簧动效

适配评估

手绘松弛

最有「人味」与个性，Excalidraw/rough.js 已验证路径。硬伤：正式演示场景偏弱；rough 波浪在大图下易乱；与实体升格后的「工单感」气质需调和。

方向 C

玻璃工具感

深色底 + 半透明圆角卡
霓虹强调 · 微光晕动效

适配评估

玻璃工具感

最现代、工具感最强（Linear/Arc 气质），深色沉浸。硬伤：浅色文档需双主题；backdrop-filter 在千级节点下性能需验证；与「纯文本文件可读」哲学距离最远。

提示：点卡片翻面。三个方向可混合（如 A 的底 + C 的深色模式），设计令牌本就可分层。
