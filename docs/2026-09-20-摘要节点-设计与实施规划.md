## 1. XMind 行为基准(调研结论,全是实测)

| # | 行为点 | XMind 实测 | 本设计对应 |
|---|---|---|---|
| 1 | 创建 | 多选主题 → 工具栏/插入菜单「概要」/ 自定义快捷键 | **两跳式创建**(见 §4.5);不引入完整多选系统(独立立项,后置) |
| 2 | 跨分支多选 | 同分支→同一概要;不同分支→各自概要 | v1:范围限定**同一父节点下的连续兄弟**;跨分支不支持 |
| 3 | 限制 | 中心主题、多个自由主题不可加概要 | v1:根节点不可为成员(无兄弟);其余同构 |
| 4 | 形态 | **方括号括线**(线型可配置)+ 短引线 + 概要主题 | 括线 + stem + 普通节点(§4.4);如想要"每成员各连一线"的放射形态 → 决策 D1 |
| 5 | 主题能力 | 普通主题:改名、样式、**可加子主题** | 摘要节点 = 普通树节点(能力天然继承) |
| 6 | 范围调整 | 选中概要 → 拖上下蓝框手柄扩缩范围 | **P2**(拖拽);P1 先做"选中高亮成员"的静态反馈 |
| 7 | 删除 | 选中概要 Delete / 右键删除 | 普通节点删除(锚随之消失,成员零影响) |

**形态细节**(逐帧核对,证据 `outputs/summary-xmind/03/05/07`):括线在成员**外侧**(远离父节点一侧),上下端有小横钩(方括号 `]` 样式,开口朝成员);引线从括线**中点**横连到摘要主题;摘要主题默认文本「概要」,可带自己的子主题(向右继续生长)。

## 2. 目标与非目标

### 2.1 一句话定义

**摘要节点 = 对同父连续兄弟 [M1..Mk] 的括线标注 + 挂在其外侧的一个普通节点。**

- 它是**普通树节点**(改名/编辑/note/删除/加子主题 —— 全部能力白拿);
- 唯一特殊:多了 `summary_of {from, to}` 锚(§4.1),布局按"卫星"处理(§4.3)。

### 2.2 用户故事

- U1:选中一组叶节点(如 829 工作流里的并列步骤)→「创建摘要…」→ 写「第 2 章全量对齐」概括该组;
- U2:摘要节点继续长自己的子主题(XMind 同款);
- U3:成员增删/重排后括线跟随;锚失效时**数据不丢**、可解释、可修复。

### 2.3 成功判据

1. 视觉与 XMind 同构:括线贴"成员带"外沿、端部横钩、stem 横连、节点居带中;
2. 数据硬纪律:roundtrip 无损;无效锚**不静默删除**(诊断 + 降级);
3. 创建=一次 Ctrl+Z 可全撤;
4. 与 sections / 折叠 / 升降格 / 框内 / 导出等既有机制的边界有明确定义(§4.6)。

### 2.4 非目标(Non-goals)

- ❌ 完整多选系统(marquee / shift 累选)——独立立项;本稿用两跳式绕开;
- ❌ 跨父/跨分支摘要;非连续成员集合(v1 只做连续 range);
- ❌ 拖拽调整范围 / 拖入拖出(v1 之后);
- ❌ 括线多套线型样式(方括号先行,样式配置后置);
- ❌ 上下生长方向(v1 只做左/右,别向 P2)——已锁定 D6。

### 3.2 缺口(本功能真正要新建的)

1. **卫星布局**——树布局没有"跳出行列、挂到兄弟带外沿"的概念,**核心工作量**;
2. **括线渲染层**(方括号路径 + stem),并抑制父边 P→S;
3. **两跳创建事务 + 范围 draft 交互**;
4. 无多选基础(用两跳式绕开,不动选区模型)。

### 3.3 硬约束

- 新元数据:**roundtrip 锁死**(新键纪律);canonical 无固定序,按插入序输出;
- **数据无损**:坏锚不静默删;诊断 + 降级(§4.2);
- memo / 预算 / 零硬编码 / 性能纪律照旧;**布局改动先跑既有布局回归测试**;
- ADR-0006:Canvas 后端可静默缺省(仅保证 SVG 路径)。

## 4. 设计

### 4.1 数据模型

**锚 = 范围两端**(连续兄弟语义;拖入即成员):

```markdown
- 成员 A
- 成员 B
- 成员 C
<!--
summary_of:
  from: cid:c7
  to: cid:c9
-->
- 第 2 章全量对齐
- 成员 D
```

- **写在摘要节点自己的 note 块**(单一事实源;**成员零写入**——除创建时为补发 cid);
- `from`/`to`:**写入一律 `cid:`**(创建事务用 `ensureNodeCid` 给端点补发);**读取兼容 `node:`** 路径锚(与 sections 同轨,迁移双轨);
- 键值形态:一层嵌套 mapping(parser 自 v1.7.0 支持,`lens` 先例;内联 JSON 亦可往返)——写入形态对齐 lens;
- 结构约束:from/to 与摘要节点**同父**;`from.index ≤ to.index`;解析期校验(§4.2)。

**为什么不做成"文档级列表"(仿 sections 数据面)**:

- 普通节点形态 = 全部节点能力白拿(编辑 / note / 子主题 / 升降格 / 复制);文档级列表会让它变成"非节点",与「节点形式」的心智不符;
- 也无需新协议字段:parser/serializer 零改动(透传纪律)。

### 4.2 解析与降级(数据无损纪律)

`resolveSummaries(root)` 仿 `resolveSections` 三态:

| 状态 | 条件 | 行为 |
|---|---|---|
| well-formed | 两端命中 + 同父 + 顺序正确 | 正常:括线 + stem + 卫星定位 |
| dangling | 端点被删 / 移出同父 / 顺序倒置 | **降级为普通节点**(回落常规堆叠)+ `W-SUMMARY-DANGLING`;**元数据保留** |
| stale | 锚不可解析(手写坏值) | 同上 |

- **中间成员变化**(删除/拖走/拖入)不触发 dangling——范围按位置**自然伸缩**(XMind 同款语义);
- 降级 = 回落普通节点渲染是刻意选择:节点永远可见、永远可编辑,绝不出现"幽灵挂件";
- 摘要节点自身被删 = 普通删除(锚消失,成员零影响)。

### 4.3 布局:卫星(本功能技术核心)

**目标形态**:S 不占父级 children 的常规堆叠槽位;放在"成员带"外沿之外、垂直居中于成员带。

**几何协议**:

1. **成员带** = [M1..Mk] 各自子树外接并集(右生长:max-right / min-top / max-bottom);
2. `bracketX = 带外沿 + gapB`;`stemY = 带垂直中心`;`S.left = bracketX + gapS`(S 盒垂直中心对齐 stemY);
3. **S 的子树**(S 带子主题时)从 S 继续向外生长(同父方向);
4. **带高整合(L2)**:父级堆叠时,该带槽高 = `max(成员带高, S 子树高)`,防止 S 子树超高时与相邻兄弟带重叠。**v1 建议直接按 L2 做**(避免"已知重叠"债务);若预研超预期 → 降级"接受极端重叠"并记录。

> 成员带子树的括线贴法:XMind 逐帧未覆盖该场景;本设计取"贴带外沿"的保守解(括线永不穿子树)。若要"贴成员盒、穿越子树",再议(可与 D1 并拍)。

**实现路径(建议)**:

- `buildLayoutTree` 阶段:识别 `summary_of` 节点 → 从 children 摘出到 side 列表(标记 satellite)→ 父级堆叠天然忽略它;
- 主布局完成后:对每个 satellite 用**已放置成员**求带 extents → 平移到目标位 → 其子树复用 build/placeSubtree 局部布局后拼接进 `layout.nodes`(parentId 保持父节点);
- **父边抑制**:不产出 P→S 的树边(括线取代);boundary links / island overview 同口径核对;
- **bounds 纳入**:S 及子树纳入父子树 bounds(AABB / 命中 / 森林投影 / sections 框)——否则拖拽与概览会漏;
- **折叠**:父折叠 → 整体隐藏(天然);成员子树折叠 → 带收缩 → 括线自动跟随。

**四向生长**:v1 支持 left/right(镜像);up/down 的旋转版 P2(决策 D6)。

### 4.4 渲染

- 新层 `SummaryLayer`(react/render,与 SectionLayer 平级):
  - 括线:方括号路径(竖线 + 上下端朝内横钩)+ stem 横线;线色/粗细先取现有 token(实现时附两种对比稿);
  - LOD:S 文本按节点既有 LOD 省略;括线本身各档保留(结构线);
- **选中反馈(P1)**:选中 S 时高亮成员(选择色描边)——即时回答"这括号括的是谁";
- **导出**:括线 + stem 与节点一并导出(仿 section 框处理);Canvas 后端=静默缺(ADR-0006)。

### 4.5 交互

**创建(两跳式,直接仿 linkDraft 先例)**:

```
① 选中首个成员节点
② 右键「创建摘要…」(环内同席位;文案:创建摘要…)
③ 进入 draft 态:提示条「点选范围末成员(需同一父级)… Esc 取消」
④ 点末成员 → 校验同父 → 单事务落盘 → 选中新摘要节点
```

- 校验失败(不同父 / 根节点)→ 提示,不落盘;
- 单击同一节点 = 单成员摘要(允许;P2 可拖拽扩范围);
- 事务 ops(单条 undo):`[ensureCid(from), ensureCid(to), insert S(范围后, note.summary_of: {from, to}), (next_cid bump 若补发)]`。

**编辑 / 删除**:全复用普通节点通路(F2 / 双击改名、Del、Shift+Enter desc、note 面板)——零新代码。

**P2 增强**(另批):拖拽手柄扩缩范围;兄弟拖入/拖出范围自动纳入/剔除;up/down;摘要子树布局打磨。

### 4.6 与周边机制的行为约定

| 机制 | 约定 |
|---|---|
| sections | 可叠加(括线在 section 框内,视觉不冲突);S 纳入 section AABB |
| 自由边 | 无关;可给 S 画自由边(自然支持) |
| 升格中心 | S 被升格 = 移出父级 → 同父校验失败 → 降级 + 诊断(自然、可解释) |
| 框内大纲(FO) | v1:框内不做括线(S 按普通行显示/隐藏);P2 评估 |
| 剪切/粘贴 | `summary_of` 登记进 `ANCHOR_NOTE_KEYS`:整段剪切(含 S 与成员)锚随 cid 保留;只剪切 S → 悬空 → 降级 + 诊断(合理) |
| duplicate(②批次) | 复制含 cid 子树会带 dup-cid 债务(既有问题,②批次一并处置) |

**验收清单**:

- [ ] roundtrip:含 `summary_of` 文档 parse → serialize → parse 无损;
- [ ] 创建:两跳全程可完成 + 单条 Ctrl+Z 全撤 + 跨父/根拒绝有提示;
- [ ] 视觉:左/右两向、三档缩放、三主题下括线位置正确(带外沿 + 居中);
- [ ] 成员增删:中间删除→括线收缩;端点删除→降级 + 诊断条出现;
- [ ] 迁移:改名/缩进某成员 → 锚自动重建、括线仍连对;
- [ ] 布局回归全绿 + pan-memo 性能不回退;
- [ ] SVG 导出包含括线。

## 6. 风险

| 风险 | 等级 | 缓解 |
