## 主控取证（已核，按此选型）

### 为何不能「展开后再 separateTree」（C2 已否决的 S1）

C2 选 **S2**：`createFrameShellMeasure` 在**基座前**注入壳尺寸；`separateTree` 只在基座期跑。展开后改盒会弄断已算好的 `links.path`。  
⇒ C2.1 必须继续走 **measure 期占位**，不能靠 expand 后再 separate。

### 鸡生蛋

挂点绝对坐标依赖基座给出的壳落点；基座又需要「含挂出」的壳尺寸。  
⇒ 占位用**相对框根、与绝对落点无关**的挂出外包络**估算**（与 FIX3 `subtreeCrossExtent` / 单岛局部 bounds 同源），并进 `frameShellSize`。

### 视觉壳 vs 占位壳（已裁定）

| | 口径 |
|--|------|
| **占位壳**（`createFrameShellMeasure` / 基座盒） | = 大纲壳 ∪ **挂出外包络**（含 `FRAME_HANG_GAP` 与跨轴堆叠） |
| **描边壳**（`FrameOutline` 画出的灰框） | **仍 = 大纲行 + `FRAME_SHELL_PAD`**（不把挂出画进灰框） |

回执须显式声明「占位 ≥ 描边」。若发现占位/描边不一致导致点击/裁剪硬伤，停报请主控裁是否放大描边。

## 口径（已裁定）

| 做 | 不做 |
|----|------|
| `frameShellSize` / 壳度量计入挂出外包络，使基座邻居与**挂出节点盒**无重叠（separate 既有容差内） | 不重写 `separateTree` 内核；不重开 FIX4（框内岛间） |
| 估算须覆盖：同挂点多同级（FIX3 跨轴堆叠）+ 多挂点行（保守按 hangRoots 顺序堆叠，≥ FIX4 推挤后高度） | 不做「展开后二次 separate」；不新 `type` |
| 无挂出（`hangRoots.length === 0`）→ 壳尺寸与 C2 **逐值一致** | 不改 Enter；不动 OutlinePanel / graph-engine |

推荐算法（可微调，回执写清公式 file:line）：

1. `outlineShell = shellOfRows(大纲行)`（现逻辑）。  
2. 对每个 `hangRoot`：用 `measure` + 与 FIX3 同款的 `subtreeCrossExtent`（或对 spatialRoot 跑一次**局部** `layoutMindmap`/`layoutForest` 单中心取 `bounds`，注意缓存/副作用）得到岛宽高。  
3. 主侧：外包络从壳缘外扩 `FRAME_HANG_GAP + 岛主侧半宽/全宽`（与 `hangOriginOf` 中心口径对齐）。  
4. 跨轴：按 hangRoots 顺序把各岛跨轴尺寸 + `FRAME_HANG_SIBLING_GAP` 累加（可整组相对大纲壳中线，或相对首挂点行；须保守不小于真实 FIX3+FIX4 堆叠）。  
5. `占位壳 = union(outlineShell, hangEnvelope)`（可再 + 少量 pad，但禁止用「只加大 FRAME_HANG_GAP」冒充并集）。

嵌套框：空间层上的框根已由 `createFrameShellMeasure` 自引用量自身壳——挂出估算须用同一 `shellMeasure`，避免嵌套漏计。
