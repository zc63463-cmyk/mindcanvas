## 三、工程发现（诚实披露）

| # | 发现 | 说明 |
|---|---|---|
| D1 | **冷增量 = O(受影响分支)**：文本宽度变化 → 祖先 xEdge 变化 → 分支放置戳失效重放（9840 节点 50ms） | T6 的 0.16ms 是热态（同参连续命中）；两者都是预期行为；门禁按实测取 50% 余量，热态门禁仍由 kernel T6 守护 |
| D2 | jsdom 环境 CPU 测速约为真实浏览器 10-50× | 验收测试全部按「宽松门禁 + 数值记录」设计，数据入档供真实浏览器对照 |
| D3 | 导出为**全图**（bounds 外扩）而非当前视口 | MapViewApi 无 viewport 访问（冻结面），全图导出覆盖完整且实现简单；当前视口导出留作 API 扩展候选 |
