# FO-UI1.1 外派任务书：框深度气泡抢焦点 + Enter 勿落到画布建同级

> **本文件即开工令**。工作目录 = mindcanvas 仓库根。  
> 阶段：**FO-UI1.1**（UI1 回归）。**前置：FO-UI1 已验收 `ca4d19a`+`0d2f864`+`83d5f5c`。**  
> 用户实测：气泡已弹出、数字可改，但 **Enter 不作用在气泡上** → 画布选中节点收到 Enter → **下面「新节点」变多**（`add-sibling`）。截图：气泡旁仍有节点绿选中环。

## 你的角色

工程执行 agent。气泡打开期间键盘必须由气泡消费（Enter=提交深度 / Esc=取消）；不得落到画布 `matchEditorKey` → 建同级。TDD。显式路径提交。不 push。

## 现象（已确认）

1. 「改框深度…」→ `FrameDepthBubble` 可见。  
2. `−`/`+` 或改数字后按 **Enter** → 深度**不**落盘，框外/旁侧节点反而新建同级。  
3. 根因：**焦点不在** `[data-frame-depth-input]` 上。  
   - 气泡仅靠 `autoFocus`；右键菜单关闭后焦点常回到画布/框行/`selectedId` 节点。  
   - 全局键位：`MindmapStage` 在 `editingId === null` 且目标非 input/textarea 时，`Enter` → `addSibling`。  
   - 气泡的 `onKeyDown` **只有焦点在 input 上才触发** → 用户按 Enter = 建节点，不是提交深度。

单测用 `fireEvent.keyDown(input, …)` **测不到**这条回归（人为把事件打在 input 上）。

## 口径（已裁定）

| 做 | 不做 |
|----|------|
| 气泡挂载后**强制** `input.focus()`（`useEffect` + ref；必要时 `requestAnimationFrame` / `queueMicrotask` 躲过菜单卸载抢焦） | 不改 `setFrameDepth` / clamp 语义 |
| 气泡打开期间：在 **window capture**（或 document）监听 Enter/Esc —— Enter → commit 当前合法值；Esc → cancel；`preventDefault` + `stopPropagation`，**阻断**画布建同级 | 不改成框默认 depth=2 |
| `−`/`+` 点击后保持/拉回 input 焦点（避免点步进后焦点落在 button，下一次 Enter 仍漏） | 不重开框内行右键 FO-UI2（可另立；本批只修气泡键位） |
| 红测：**焦点不在 input**（`document.body.focus()`）时按 Enter 仍 `onCommit`，且若有画布键位 spy 则不得触发 add-sibling | 不动 kernel 布局 |

**推荐增强（本批可做，回执声明）**

- `−`/`+` **立即** `onCommit(clamp(n))` 并关气泡，或立即 commit 且保持气泡 —— 二选一；优先「步进即提交并关闭」减少「必须再按 Enter」认知负担。若采用，Enter 仍保留为「手输后提交」。  
- 文案旁弱提示「Enter 确定」可选，非必须。

## 必须交付的测试（先红后绿）

```ts
it('★ 焦点不在 input 时 Enter 仍提交，不依赖 autoFocus', () => {
  const { input, onCommit } = renderBubble({ current: 2, max: 5 });
  fireEvent.change(input, { target: { value: '3' } });
  (document.activeElement as HTMLElement | null)?.blur?.();
  document.body.tabIndex = -1;
  document.body.focus();
  // 派发到 window（模拟画布快捷键路径前的捕获）
  fireEvent.keyDown(window, { key: 'Enter' });
  expect(onCommit).toHaveBeenCalledWith(3);
});
```

若实现 capture 监听，断言须与实现一致（`window` vs `document`）。另补：打开气泡后 `expect(input).toHaveFocus()`（在 jsdom 尽力；若 jsdom 弱则至少测 listener 路径）。
