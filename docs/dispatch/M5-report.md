## 三、工程决策与冲突记录

### 决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 动画内核升级为**多命名槽**（`animate(opts, name)`） | T2 节点过渡与 T3 视口动画可能并发（折叠动画中按 Ctrl+F 定位）；单槽会互相打断导致视口半途冻结。默认槽语义兼容 T1，未冻结面内部演进 |
| D2 | 节点过渡**帧间插值**（NodeFrame → NodeFrame），而非布局前后快照硬编码 | 帧间插值天然支持打断续接（新动画 from = 当前插值帧），ghost 淡出可携带 |
| D3 | 节点过渡规模阈值 3000 跳过动画（NODE_ANIM_MAX_NODES） | 大图每帧重渲全量可见 DOM 会跌破 50fps；阈值外直接落位（正确性不受影响） |
| D4 | 增量布局缓存以 **EditableNode 身份**为键 + collapsedKey/measureKey 双键失效 | 不可变树编辑只改路径节点身份；折叠集对象身份变化或度量语义变化 → 自动全量重算（结果恒等于全量，正确性由构造保证） |
| D5 | 收集/包围盒按子树缓存，放置重放时失效 | 连线 path 字符串构建是全量布局的最重开销（87K 时 ~48ms），缓存后增量 O(1) 命中 |
| D6 | 拖拽落点子树的**目标可命中但判非法**（warn 反馈），而非排除子树 | 悬停自身子树必须给出拒绝反馈（任务要求「拒绝并给出视觉反馈」），排除则无反馈 |
| D7 | 渲染后端 = 场景原语（后端无关）+ 适配器；MapView 连线先接线 | Canvas 后续可直译场景原语为绘制调用，切换点清晰；连线是最大 DOM 开销（T8 实证） |

### 冲突 / 阻塞与处置

| # | 冲突 | 处置 |
|---|---|---|
| C1 | **treeOps 结构共享缺失（阻塞 T6）**：`updateNode`/`addChild` 克隆全部内部节点（仅叶保持身份）→ 增量缓存的「未变子树身份不变」前提被破坏（实测高度缓存 miss 3280/9841 次） | 修复 treeOps：未变子树保持对象引用（removeNode 已有同款模式）。**输出语义完全不变**（行为级等价，非签名变更），作为 T6 阻塞项修复并在本报告记录 |
| C2 | 动画结束的**末帧 notify 广播**产生一帧合法渲染帧（hasPending 短暂非零） | 判定为合法（展示最终态的渲染帧），测试多 flush 一次消费；「3 秒归零」验收不受影响 |
| C3 | kernel HP1 测试要求根节点也在 subtreeHeight 缓存 | 补 `subtreeHeightCached(rootNode)` 预热（未变子树全命中，增量成本 ≈ O(N) WeakMap get，实测可忽略） |
| C4 | jsdom 无尺寸 → 视口裁剪致 DOM 基准可见集过小 | 计算侧精确测量（bench-scale.mjs 全视口最坏情形）+ jsdom 仅作完整链路上界代理，文档如实标注口径 |

### 冻结纪律（ADR-0004）

- 全部为 **minor（可加不可改）**：新增导出（LayoutCache/LayoutOptions/easing 集/animate/transition/nodeDrag/RenderBackend）、新增可选参数（layoutMindmap 4 参 opts / NodeG.anim / MapView.onNodeMove 等 prop）
- **无 major**；treeOps 修复为行为级等价（输出树值不变），未改签名
- 透传铁律与三主题形态未触及（全部视觉值走 token/motion 常量，组件内零硬编码）
