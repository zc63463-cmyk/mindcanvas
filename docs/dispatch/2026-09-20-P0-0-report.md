- 现象：`git update-ref` 报告成功，但 `refs/heads/codex/**` 下的**引用文件被环境回滚**（同一命令内 `git show-ref --heads` 即只剩 `main`）。`.git/logs/refs/heads/codex/*` 的 reflog 与 `.git/objects/**` 的对象**均保留**（冻结 commit 对象未丢）。
