## 四、Canvas 模式的能力边界（诚实披露）

| 能力 | SVG 模式 | Canvas 模式 |
|---|---|---|
| 节点卡/文本/连线/折叠计数/选中描边 | ✅ | ✅ |
| 点击选中 / 拖拽重排 / pinch 缩放 / 右键菜单 | ✅ | ✅（坐标命中） |
| hover 高亮 / 内联编辑浮层锚定节点 | ✅ | 编辑浮层可用（容器层 div），hover 无 |
| 折叠按钮点击 / 资产图片绘制 | ✅ | ❌（走右键「折叠」/骨架跳过） |
| 实体徽章 / 多行文本换行 | ✅ | 骨架版简化（单行） |

> 定位：Canvas 模式是**超大图的浏览+轻交互降级态**，不是全功能替代。编辑建议折叠后回 SVG 档（<5K）或等主循环深化。
